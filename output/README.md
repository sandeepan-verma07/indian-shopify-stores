# Result: 1,000 Indian Shopify stores

| File | Format |
|---|---|
| [`stores.csv`](stores.csv) | one row per store (UTF-8; opens in Excel with Indian characters intact) |
| [`stores.json`](stores.json) | the same data; emails and phones as lists |

Both are generated by `build_final.py` — don't edit them by hand (corrections go in `data/manual_overrides.csv`).

## Columns

| Column | Brief's field | Meaning |
|---|---|---|
| `rank` | | 1 = best-ranked (quality score, see main README §2 Step 7) |
| `store_name` | | the store's own name from its Shopify settings |
| `domain_url` | Domain URL | the store's primary (custom) domain |
| `emails` | All contacts | every email shown on the store's own pages and confirmed live; placeholders / shared addresses removed; `; `-separated |
| `phones` | All contacts | every valid Indian phone number shown on the site and confirmed live, `+91…` format; `; `-separated |
| `instagram`, `facebook`, `twitter`, `linkedin`, `youtube` | Socials | profile links from the site (`twitter` holds Twitter or X links); empty if the store has none |
| `category` | Category | one of 20 categories (+ audience for apparel), from the store's own products, confirmed by a second method |
| `tagline` | Tagline / description | the store's own words, verbatim (≤ 300 characters) |
| `tagline_source` | | where the tagline was copied from (`meta_json`, `about_meta_description`, `about_paragraph`, …) |
| `logo_url` | Logo | brand logo image URL (not the favicon); checked to load |
| `state`, `city` | State | business location from the store's Shopify settings, cross-checked with its GST number where shown |
| `gstin` | | the store's GST number, if printed on its site (extra India proof) |
| `india_evidence` | | why the store counts as Indian (e.g. `meta.json country=IN; currency=INR; state=Kerala; +91 phone on site`) |
| `quality_score` | | ranking score, 7–13 |

Every field of all 1,000 stores was re-checked on the live websites: see [`../reports/audit.md`](../reports/audit.md).
